# Aaryan Patel | Portfolio

A single-page portfolio built as a scroll-driven drive down Interstate 280, from San Francisco south to Menlo Park.
Selected work comes first as points of interest, experience entries are exits, and the last sign is the Sand Hill Road exit.

Live: https://aaryanp35.vercel.app (Vercel, deploys from `main`)

## World

The Caltrans sign system is the material: guide green, recreation brown, service blue, white Overpass lettering.
Sign yellow is used only for actions (Resume and Email). Behind the signs a fixed scene of layered SVG hills, the
Crystal Springs reservoir, the Stanford dish, Karl the Fog, a warming horizon light and a road with a moving centerline
changes as you scroll. A mile counter and a route dot in the top bar track the drive.

## Stack

- Plain HTML, CSS and JavaScript, no build step for the site itself.
- GSAP 3.13.0 with ScrollTrigger and MotionPathPlugin, and Lenis 1.3.1 on fine pointers, pinned CDN versions in `index.html`.
- Fonts from Google Fonts: Overpass (signs), Source Serif 4 (body), Azeret Mono (miles and dates).
- The landscape is generated by `assets-src/build_assets.py` (fixed seed) and inlined by `assets-src/inline.py`.

## Run locally

```
python3 -m http.server 8000
```

Then visit http://localhost:8000. To regenerate the page after editing `assets-src/index.template.html`:

```
python3 assets-src/build_assets.py && python3 assets-src/inline.py
```

## Structure

```
index.html            Generated page (markup, head metadata, inline SVG scene)
styles.css            Tokens, signs, gantries, layout
script.js             One master timeline, mile counter, route dot, static drive
assets-src/           SVG generators, page template, inliner
images/ resume.pdf    Portrait, icons, resume
```

## Behavior

- Content is visible without JavaScript. Hidden start states apply only under `html.js`, with a 3 second backstop.
- With reduced motion, nothing moves: the scene swaps to a fixed state per stretch and the counter simply follows scroll.
- On phones the Points of Interest Ahead strip sits directly under the action buttons, inside the first screen, and scrolling is native (no smoothing library, no continuous fog drift).
- Section ids keep their original names but follow document order: `#crystal-springs` (Selected work, the fog stretch) comes before `#daly-city` (Experience, the reservoir stretch).
- `images/og-image.jpg` and the icons are rendered from the sign vocabulary; their provenance is embedded in the files.
